# Dark Industrial Modernism

The redesign uses a masculine system built from obsidian, graphite, steel, cobalt, signal orange, and tungsten amber. It combines Dark Mode First, Modernist, Neo-Geo, Corporate Professional, and Tech Forward principles.

The page narrative is capability, method, sector command, regional operations, and a decisive sourcing brief. Motion is calibrated and mechanical rather than liquid or playful. Glass is limited to functional elevated surfaces; the foundation is hard geometry, strong contrast, and operational clarity.

Future client portal work requires real authentication, authorization, secure document storage, audit logs, and a server-side application. It must not be simulated on static GitHub Pages.
