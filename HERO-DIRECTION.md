# Single hero direction

The landing page uses one large, documentary-style industrial image as its sole visual focal point. The image is framed edge-to-edge inside the hero, supported by a dark readability gradient and a small operational label rather than competing cards or secondary image panels.

The selected visual language blends Modernist clarity, Corporate Professional credibility, Tech Forward accent colors, and Luxury Minimal restraint. The result should feel established and premium while keeping the eye anchored on one decisive image.

Below the hero, imagery is intentionally removed. Sector cards rely on typography, numbering, translucent layers, and functional copy so the first impression remains visually singular. The page retains responsive behavior, keyboard focus, dark mode, reduced-motion support, explicit image dimensions, and transparent quote-form status.
