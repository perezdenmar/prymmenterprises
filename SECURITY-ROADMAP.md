# Platform roadmap

The current site is a static GitHub Pages experience. It must not present a client portal, shipment dashboard, secure document exchange, or authenticated workflow until a real application layer exists.

## Future portal requirements
- Managed identity and multi-factor authentication.
- Role-based access for buyers, internal staff, and suppliers.
- Server-side authorization on every request.
- Encrypted document storage with expiring access links.
- Audit logs, session controls, backups, and incident response.
- Explicit privacy, retention, and data-processing policies.

Until those controls exist, keep the client portal described as a future capability and route sourcing through an approved, secured endpoint.
